# 初始化项目提示词

请读取仓库根目录的 `AGENTS.md` 和 `docs/00` 到 `docs/09`。

任务：初始化 AI QA Assistant 的最小可运行工程骨架。

范围：

1. Python 3.12 + uv + FastAPI + Pydantic v2 + SQLModel + Alembic。
2. Vue 3 + TypeScript + Vite + Element Plus + Pinia。
3. Tauri 2 桌面容器。
4. 本地 FastAPI 只监听 127.0.0.1，提供 `/health`。
5. 桌面页面显示后端健康状态和版本。
6. 添加 Ruff、mypy、pytest、前端 lint/typecheck/test/build。
7. 添加基础 CI。

非目标：不实现 AI、文档解析、测试执行和用户系统。

先不要修改代码。先输出：

- 现有仓库状态。
- 目标目录结构。
- 依赖清单及引入理由。
- 分步骤计划。
- 风险与需要我确认的问题。
- 验收标准与测试映射。

得到确认后再实现。实现完成后运行全部可用质量命令并逐项汇报真实结果。
