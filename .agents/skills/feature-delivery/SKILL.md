# Feature Delivery

1. 复述已确认目标、非目标和验收标准。
2. 检查工作区和 Git 状态，避免覆盖用户改动。
3. 先补领域/回归测试，再实现最小代码。
4. 严格遵循分层，外部依赖通过适配器。
5. 数据库变化必须添加 Alembic 迁移和迁移测试。
6. 长任务进入 Worker，支持进度、取消、超时和错误终态。
7. 运行最小测试后运行仓库质量门禁。
8. 自审 diff，删除调试代码和无关改动。
9. 更新相关文档。
10. 汇报修改、命令结果、未验证项和残余风险。
