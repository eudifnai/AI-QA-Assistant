# Requirement to Plan

1. 读取根目录 `AGENTS.md`、相关 `docs/` 和现有代码。
2. 不立即修改代码。
3. 区分事实、需求、假设和待确认项。
4. 输出目标、非目标、用户流程、异常流程和数据流。
5. 标注对数据库、API、前端、Worker、模型和安全的影响。
6. 生成不超过 8 步的垂直切片计划。
7. 将每条验收标准映射到测试类型和验证命令。
8. 对范围、依赖或不可逆决策提出明确问题。
9. 等待用户确认后才进入实现。
