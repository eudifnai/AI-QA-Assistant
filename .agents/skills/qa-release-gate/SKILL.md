# QA Release Gate

1. 读取 PRD、验收清单、CHANGELOG 和当前 diff。
2. 检查质量命令、核心闭环、数据库升级和安装包冒烟结果。
3. 优先识别 P0/P1：数据损坏、密钥泄露、隐式外发、无法启动、迁移失败、任务不可取消或核心功能不可用。
4. 检查本地 API 边界、日志脱敏、Worker 崩溃恢复和模型不可用降级。
5. 区分：已验证通过、未验证、已知失败、环境阻塞。
6. 不把“代码看起来正确”当作测试通过。
7. 输出结论：Go、Conditional Go 或 No-Go。
8. 给出阻塞项、非阻塞风险和发布后观察项。
