# 技术架构设计

## 1. 总体架构

```text
Tauri 2 Desktop
└── Vue 3 / TypeScript / Element Plus
        │ HTTP + WebSocket (127.0.0.1 + session token)
        ▼
FastAPI Local Service
├── Workspace / Documents / Cases / Reports API
├── AI Orchestration
├── Job Manager
└── Local Tool Gateway
        │
        ├── SQLite + SQLModel + Alembic
        ├── Qdrant Local + embedding model
        ├── Ollama / OpenAI-compatible model
        └── Python Worker Processes
             ├── HTTP Runner
             ├── WebSocket Runner
             ├── Protobuf Runner
             ├── Playwright Runner（后续）
             └── Appium / Unity Adapter（后续）
```

## 2. 进程模型

### 桌面主进程

负责窗口、托盘、文件选择、应用目录、更新和 FastAPI Sidecar 生命周期。

### FastAPI API 进程

负责短请求、数据查询、任务创建、WebSocket 推送和健康检查。禁止在该进程直接执行长时间 LLM 推理或自动化测试。

### Worker 进程

负责文档解析、向量化、LLM 分析、测试执行和报告生成。每个任务记录 PID、心跳、进度和取消标记。

## 3. 后端分层

```text
backend/
├── app/
│   ├── api/               # FastAPI routes / dependencies
│   ├── application/       # use cases / orchestration
│   ├── domain/            # entities / value objects / state machines
│   ├── infrastructure/    # db / files / llm / vector / tool adapters
│   ├── workers/           # long-running jobs
│   ├── schemas/           # external request/response schemas
│   ├── core/              # config / security / logging / errors
│   └── main.py
├── migrations/
└── tests/
```

推荐三栏布局：左侧工作空间导航，中间 AI/业务工作区，右侧任务、日志和产物面板。

## 5. 数据模型

核心实体：

- `Workspace`：本地工作空间。
- `Project`：产品或测试项目。
- `Document` / `DocumentVersion` / `DocumentChunk`。
- `AnalysisRun` / `AnalysisIssue` / `SourceCitation`。
- `TestPoint` / `TestCase` / `TestStep`。
- `Environment` / `SecretReference` / `ProtoAsset`。
- `TestSuite` / `Execution` / `CaseResult` / `Artifact`。
- `ModelProfile` / `Conversation` / `Message`。
- `Job` / `JobEvent`。

所有实体使用 UUID；时间统一存 UTC，UI 按本地时区显示。

## 6. 任务状态机

```text
pending → queued → running → passed
                    ├──────→ failed
                    ├──────→ error
                    ├──────→ cancelled
                    └──────→ timeout
```

终态不可直接回到运行态；重跑创建新的 Execution，并通过 `retry_of_id` 关联原任务。

## 7. AI 架构

业务层依赖抽象接口：

- `ChatModelProvider`
- `EmbeddingProvider`
- `StructuredOutputParser`
- `PromptTemplateRepository`
- `RetrievalService`

需求分析采用“切片检索 + 分维度分析 + 汇总去重 + Schema 校验”的确定性流程，不让单个自由 Agent 无限制循环。

## 8. 本地安全

- FastAPI 启动时生成随机端口和一次性会话令牌，通过安全 IPC 交给前端。
- 仅允许 Origin 为桌面应用的请求。
- 文件路径统一经过 `resolve` 和工作空间边界检查。
- 外部命令使用 allowlist 适配器；默认禁止任意 Shell。
- API Key 存在系统凭据库，数据库只保存引用 ID。
- 报告、日志、Prompt 进入模型前执行脱敏策略。

## 9. 打包

- 前端由 Vite 构建。
- FastAPI 及 Python Worker 打包为 Sidecar，可选择 PyInstaller 或 Nuitka 进行评估。
- Tauri 生成 Windows/macOS 安装包。
- 每个平台独立构建和签名，不进行跨平台交叉打包。
