# 里程碑与任务拆分

以下是个人开发的建议节奏，时间是估算，用于排优先级，不构成承诺。

## M0：工程骨架（2-4 天）

- 初始化 Git、uv、pnpm、Vue、Tauri、FastAPI。
- 统一配置、日志、错误码、健康检查。
- SQLite + Alembic 首个迁移。
- 本地 API 启动令牌与桌面启动联动。
- CI 基础质量门禁。

完成标准：桌面应用可启动，显示 FastAPI 健康状态，测试与构建命令可执行。

## M1：工作空间（3-5 天）

- 创建/打开工作空间。
- 最近项目和本地目录。
- 用户设置、模型占位配置。
- 数据备份与诊断页面。

## M2：文档管线（5-8 天）

- 文档模型、版本和文件哈希。
- Markdown/TXT 优先，随后 DOCX/PDF。
- Worker 解析、进度、取消和错误恢复。
- 文本预览和引用定位。

## M3：AI 分析（7-10 天）

- Provider 抽象与 Ollama/OpenAI-compatible 实现。
- 需求分析 Schema 和 Prompt。
- 分维度分析、汇总、引用和人工确认。
- Qdrant Local 索引。

## M4：测试设计（5-8 天）

- 测试点生成和编辑。
- 测试用例模型、步骤和批量确认。
- 需求追踪矩阵。
- 自动化候选规则。

## M5：接口执行（10-15 天）

- Job Manager 与 Worker 生命周期。
- HTTP Runner。
- WebSocket Runner。
- Protobuf 动态编解码。
- 实时日志、取消、超时、重跑。

## M6：报告与首发（7-10 天）

- 结果聚合、趋势和 AI 失败归因。
- HTML/Markdown/JSON 导出。
- 打包、升级、数据迁移和安装冒烟。
- 用户手册、发布说明和已知问题。

## MVP 之后

1. Playwright Web UI 自动化。
2. Appium Android/iOS。
3. Unity Poco/Airtest 或自定义 SDK 适配。
4. 钉钉文档连接器。
5. Git 仓库代码上下文和变更影响分析。
6. 团队共享与可选服务端模式。
