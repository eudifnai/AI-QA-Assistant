# MVP 验收清单

## 用户闭环

- [ ] 用户可创建工作空间并在重启后恢复。
- [ ] 可导入至少 Markdown、DOCX、PDF 和 Proto 文件。
- [ ] 可查看解析结果和错误。
- [ ] 可生成带引用的需求分析。
- [ ] 可确认并生成测试点和测试用例。
- [ ] 可配置 HTTP/WebSocket 环境和安全变量。
- [ ] 可运行至少一个 Protobuf 接口测试。
- [ ] 可实时查看进度并取消任务。
- [ ] 可查看结果、失败原因和脱敏日志。
- [ ] 可导出报告。

## 工程质量

- [ ] 数据迁移验证通过。
- [ ] Worker 崩溃不会导致桌面应用整体退出。
- [ ] 关键领域逻辑有单元测试。
- [ ] 核心闭环有端到端测试。
- [ ] Windows 安装包在干净环境启动成功。
- [ ] 本地 API 不可从局域网访问。
- [ ] API Key 不出现在日志、数据库明文和报告中。
- [ ] 本地模型模式无隐式外发。

## 文档

- [ ] 安装与环境要求。
- [ ] 首次使用向导。
- [ ] 模型配置与隐私说明。
- [ ] Proto/HTTP/WebSocket 使用示例。
- [ ] 常见错误和诊断方法。
- [ ] 数据备份、恢复和卸载说明。
