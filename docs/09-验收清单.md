# MVP 验收清单

## 用户闭环

- [x] 用户可创建工作空间并在重启后恢复。
- [x] 用户可重命名工作空间，并在二次确认后仅删除应用记录且保留本地目录。
- [x] 用户可持久化主题和模型配置；本地/云端模式遵守地址与外发同意约束。
- [x] 设置接口拒绝 API Key 等额外字段；仅在用户主动发起并完成适用确认后连接已展示的本地或云端模型。
- [x] 模型 API Key 可写入和清除操作系统凭据库，接口与前端均不回显或持久化密钥值。
- [x] 用户可查看本机与数据库诊断，并手动创建通过完整性检查的 SQLite 一致性备份。
- [x] 数据库备份不包含工作空间原文件或系统凭据，当前界面不提供恢复和删除。
- [x] 可从系统文件选择器导入工作空间内的 Markdown/TXT，并按 SHA-256 拒绝重复内容。
- [x] Markdown/TXT 解析运行于独立 Worker，可查看进度、错误和文本预览并取消任务。
- [x] 可导入并预览 Markdown、TXT、DOCX 和非加密文本型 PDF。
- [x] 可导入工作空间内的单文件 Proto，查看 package、service/RPC、message、enum 和字段，并按冻结
  描述符执行本地 JSON/Base64 动态编解码。
- [x] 可查看当前支持文档的解析结果和安全错误提示。
- [x] 可查看带稳定 ID、来源范围和字符偏移的文档引用片段。
- [x] 可通过系统多选或桌面拖拽导入最多 50 个文档，并查看逐文件成功/失败结果。
- [x] 可使用本地 Ollama 生成覆盖固定五维且每个问题带稳定文档引用的需求分析。
- [x] 可在设置级同意和每次逐次确认后使用 OpenAI-compatible 云端分析；确认展示完整请求 endpoint，
  运行冻结 `base_url`，版本、Provider、模型和输入范围快照均可审计。
- [x] 可逐条接受/拒绝待确认问题，并幂等生成、编辑、确认或禁用带来源引用的测试点。
- [x] 可由已确认测试点幂等生成、编辑并批量确认或禁用结构化测试用例。
- [x] 可按稳定引用、人工结论、测试点和测试用例查看并筛选需求追踪矩阵及覆盖缺口。
- [x] 可查看带规则编号和理由的自动化候选建议，新对象自动继承且已有草稿可显式应用。
- [x] 可配置并复用 HTTP/WebSocket 环境、普通变量和操作系统凭据库安全变量。
- [x] 可运行至少一个非流式 Protobuf HTTP 二进制接口测试，并查看解码结果与字段断言。
- [x] 可通过统一任务事件流实时查看五类长任务进度、在断线时恢复，并继续取消任务。
- [x] 可在任务更新后查看结果、稳定失败原因和已持久化的脱敏安全事件。
- [x] 可查看工作空间执行统计、分析/测试设计摘要，并通过系统保存对话框导出脱敏 JSON、Markdown 或
  HTML 报告；请求/响应正文、变量值和凭据不进入报告。
- [x] 可查看最近 14 个 UTC 自然日趋势，以及带稳定规则 ID/理由的产品、环境、数据、脚本、未知本地
  初步归因；界面明确说明不调用模型且未知项需人工复核。

## 工程质量

- [x] 当前数据库迁移的升级、降级和约束验证通过。
- [x] 文档解析与需求分析 Worker 崩溃不会导致桌面应用整体退出，并会记录安全错误状态。
- [x] 当前已交付领域规则有单元测试。
- [x] 核心闭环有端到端测试；临时 SQLite/工作空间和回环确定性服务串联真实 FastAPI、三个独立 Worker、
  测试设计持久化与报告导出，不访问外网或系统模型凭据。
- [x] Windows 安装包在一次性 GitHub hosted Windows runner 启动成功。
- [x] Windows 安装生命周期脚本覆盖制品哈希、安装、Sidecar/迁移/renderer 就绪证据、卸载和用户数据
  保留，并要求显式授权系统变更；开发机当前用户与实际 GitHub hosted Windows runner 均已通过。
- [x] Squirrel 事件处理不会等待 `Update.exe` 关闭；卸载只接受 Electron/Squirrel 固定墓碑残留，
  记录后清理测试安装根，任意未知残留均拒绝。
- [x] Windows Squirrel 未签名内部安装器候选可生成，Setup.exe、full.nupkg、RELEASES 与
  `SHA256SUMS.txt` 完整，清单重新计算一致且更新包包含 Python Sidecar。
- [x] Windows x64 Electron Forge 源码候选目录可有限时间生成，并从仓库启动验证 `app://` renderer、
  sandbox `desktopBridge` 和随机令牌后端 `/health` 200；此项不替代干净环境安装包验收。
- [x] Windows x64 Forge package 候选内置独立 PyInstaller Sidecar；冻结态可自动迁移独立用户数据库、
  执行随机令牌鉴权与连续请求、调用内置 Protobuf 编译器，并在父进程心跳停止后退出。
- [x] 本地 API 配置和所有启动入口只接受 `127.0.0.1`；真实桌面子进程 listener、Electron 就绪证据
  与安装生命周期门禁均验证回环绑定，不监听通配或局域网地址。
- [x] API Key 不出现在 API 响应、验证详情、SQLite 明文和前端 Store 中。
- [x] 本地分析只允许回环 Ollama 地址；云端只允许 HTTPS，并通过 POST 校验版本、Provider、模型、
  `base_url`、片段数和字符数快照，任一变化都拒绝并要求重新确认。
- [x] 云端 API Key 仅由 Worker 子进程从操作系统凭据库读取，不进入 SQLite、进程参数或日志。
- [x] 本地与云端之间无自动回退，云端认证、限流、超时、拒绝和无效响应均返回安全错误。
