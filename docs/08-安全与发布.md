# 安全与发布

## 1. 威胁范围

重点防护：恶意文档、路径穿越、命令注入、Prompt Injection、密钥泄露、日志泄露、桌面本地 API 被其他进程调用、自动更新被篡改。

## 2. 安全控制

- 文档解析 Worker 使用独立进程和资源上限。
- HTML 不执行脚本；PDF/Office 解析不启用宏。
- 检索内容作为“不可信资料”进入 Prompt，不允许覆盖系统指令。
- 外部命令使用明确适配器和参数 allowlist。
- 本地 API 使用随机端口、启动令牌、Origin 校验和短生命周期。
- 报告导出前再次脱敏。
- 云模型调用展示 Provider、模型、发送内容范围和隐私提示。

## 3. 发布流程

1. 冻结版本和功能范围。
2. 更新版本号、迁移、用户文档和 CHANGELOG。
3. 执行完整 CI 与端到端测试。
4. 在干净虚拟机验证安装、首次启动和卸载。
5. 从上一稳定版验证升级和数据迁移。
6. 生成安装包、SBOM、校验和并签名。
7. 发布候选版，完成小范围验证。
8. 发布稳定版并保留回滚安装包。

## 4. 数据升级

- 应用启动前备份 SQLite。
- Alembic 迁移失败时不继续启动业务服务。
- 数据目录版本与应用版本分别记录。
- 降级不自动执行逆迁移；使用备份恢复。

## 5. 发布清单

- [ ] 所有 Gate 通过。
- [ ] 安装包签名有效。
- [ ] 无明文密钥与调试端口。
- [ ] 用户数据目录和卸载行为已验证。
- [ ] 本地模型、无模型和云模型三种模式均有明确行为。
- [ ] 已知问题、兼容系统和外部依赖已记录。
